# 03 - Fundamentos de Lógica y DOM en JavaScript 

En este nivel dejé atrás el diseño estático para enfocarme en la interactividad. Es una colección de utilidades y juegos desarrollados con JavaScript puro (Vanilla JS).

##  Conceptos Aplicados:
- **Manipulación del DOM:** Uso de `document.querySelector`, `value` y manejo de eventos.
- **Interactividad Dinámica:** Función `toggle` con `classList` (add/remove) para estados visuales.
- **Lógica de Programación:** Estructuras de control y funciones para:
  -  **Piedra, Papel o Tijera:** Lógica de comparación.
  -  **Adivina el número:** Generación de números aleatorios y validación.
  -  **Comparador de números:** Algoritmo para determinar el mayor.
- **Eventos en Tiempo Real:** Contador de caracteres mediante la captura de inputs.

##  Tecnologías:
- **HTML5**
- **JavaScript (ES6+)**
